
# SciNets System Evaluation Summary

## Executive Summary
SciNets has been verified as a **functional "Ideation Engine"** capable of discovering novel scientific connections (`Symbolic novelty`). However, it faces a **critical "Grounding Bottleneck"** in its generative phase, where the LLM struggles to translate complex, diverse graph paths into coherent text without collapsing to generic summaries.

## 1. System Capabilities (What Works)
- **Graph Construction:** The system reliably builds high-fidelity concept graphs from literature (N=10 papers is sufficient).
- **Algorithmic Discovery:** The pathfinding algorithms (Dijkstra, Yen's K-Shortest) successfully identify valid, multi-hop reasoning chains that mere keyword search (RAG) misses.
- **Short-Range Reasoning:** For paths of length 3-4 (Shortest Strategy), the system shows **near-perfect fidelity**, with the realized text matching the symbolic path exacty.

## 2. System Limitations (What Doesn't Work)
- **The "Reasoning Horizon":** We reached a discrete performance cliff at **Path Length > 4**.
    - *Observation:* Correlation(Path Length, Drop Rate) = **0.86**.
    - *Impact:* Long, meandering paths generated by the "Full" strategy (intended for novelty) often create cognitive overload for the synthesized LLM, causing it to ignore the path entirely ("Collapse").
- **Diversity vs. Grounding Trade-off:** High structural diversity (Novelty) strongly correlates with generation failure. The system can *find* a novel path but often cannot *explain* it convincingly.

## 3. Recommendations
- **Optimal Configuration:** Use **"Shortest Path"** or **"K-Shortest (Small K)"** for reliable, explainable discovery. Avoid large-scale "Full" diversity searches unless human-in-the-loop verification is available.
- **Future Improvement:** The bottleneck is not the graph algorithm but the **Context Window / Reasoning Capacity** of the generic LLM used for synthesis. Fine-tuning on "Scientific Chain-of-Thought" or using a larger model context would likely extend the reasoning horizon.

## 4. Conclusion
SciNets is stable and scientifically valid as a **Search Tool** (finding the path). As a **Writer** (explaining the path), it is reliable only within a short logical horizon. It effectively bridges the gap between "Search" and "Reasoning," provided the user respects the complexity limits.
